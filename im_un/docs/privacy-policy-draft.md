# ร่างนโยบายความเป็นส่วนตัวสำหรับแอปอิ่มอุ่น

**ร่างสำหรับเจ้าของแอปตรวจสอบก่อนเผยแพร่** — ยังไม่ใช่นโยบายฉบับใช้งานจริง ต้องเติมชื่อผู้รับผิดชอบ ช่องทางติดต่อ วันมีผล และตรวจสอบพฤติกรรมแอปและบริการภายนอกบนรุ่น release ก่อนนำขึ้นเว็บไซต์หรือใส่ลิงก์ในแอป

## ผู้รับผิดชอบและช่องทางติดต่อ

ผู้รับผิดชอบ: [ระบุชื่อบุคคลหรือนิติบุคคล]
ช่องทางติดต่อและคำขอเกี่ยวกับข้อมูล: [ระบุอีเมลหรือช่องทางติดต่อ]
วันที่มีผล: [ระบุวันที่]

## ข้อมูลและวัตถุประสงค์

แอปใช้ข้อมูลที่ผู้ใช้กรอกเพื่อคำนวณน้ำหนัก พลังงานและโปรตีน และบันทึกประวัติอาหาร เช่น น้ำหนัก ปริมาณอาหาร ผลคำนวณและวันที่ รายการที่ใช้จริงต้องตรวจสอบให้ครบก่อนเผยแพร่ ข้อมูลเหล่านี้อาจเป็นข้อมูลเกี่ยวกับสุขภาพ

## การจัดเก็บและการป้องกัน

ตามโค้ดรุ่นปัจจุบัน แอปจัดเก็บประวัติในฐานข้อมูลบนอุปกรณ์และเข้ารหัสข้อมูลโดยใช้กุญแจที่จัดเก็บผ่านระบบของแพลตฟอร์ม แอปยังไม่มีระบบกู้คืนกุญแจที่ทดสอบแล้ว การลบแอป ล้างข้อมูล เปลี่ยนเครื่อง หรือกู้คืน backup อาจทำให้ไม่สามารถเข้าถึงประวัติได้ ผู้ใช้ควรได้รับคำอธิบายที่ถูกต้องในแอปก่อนเผยแพร่

[ผู้รับผิดชอบต้องตรวจสอบและระบุรายละเอียดการสำรองข้อมูลของ iOS และ Android รวมถึงบริการ SDK หรือเครือข่ายที่อาจรับข้อมูล ก่อนเผยแพร่ ห้ามสรุปว่าไม่มีการส่งข้อมูลจนกว่าจะตรวจสอบเสร็จ]

## ระยะเวลาและการลบข้อมูล

[ระบุระยะเวลาการเก็บ วิธีลบข้อมูลในแอป การลบแอปและ backup รวมถึงช่องทางติดต่อสำหรับคำถามและคำขอที่เกี่ยวข้องให้ตรงกับการทำงานจริง]

## ข้อจำกัดด้านสุขภาพ
